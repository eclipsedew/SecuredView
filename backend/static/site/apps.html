In the app

Defaults that assume you want to be protected.

The settings below are on when you first open it. You can turn any of them off, and none of them ask you to upgrade.

On by default

Kill switch

If the tunnel drops, traffic stops rather than falling back to the open network. Most clients make you find this setting. Ours starts on.

On by default

Lookups stay inside

Name resolution happens on the exit node, so queries never leak to whatever resolver your network handed you.

Optional

Per app routing

Send your browser through the tunnel and leave your banking app on the local network, or the other way around. Android and desktop.

Optional

Trusted networks

Name the networks you consider safe, usually home. Everywhere else, the app connects before you have thought about it.

Setup

From download to connected.

Four steps, in order, and the middle two take a few seconds each.

01

Install it

Store or direct file

Take the build for your platform from this page or from the official store listing. On desktop, the installer asks for permission once so it can create the network interface.

02

Open it

No account screen

There is nothing to sign into. The app fetches a set of keys on first launch and holds them locally. If you delete the app, those keys are gone and the next install is a new stranger to us.

03

Pick where to leave from

76 cities, or automatic

Automatic picks the closest healthy node, which is usually the fastest. Choose a specific city when you need to appear somewhere particular.

04

Turn it on

Roughly one second

The handshake completes and the readout shows your exit, cipher and throughput. Leave it on. There is no reason built into our side for you to turn it off.

Routers and manual setup

For everything the app cannot reach.

Televisions, consoles and anything else without a client of its own can go through a router instead. The configuration file is plain text and you can read every line of it.

  • Router firmware with support for the standard client, which covers most current builds
  • One configuration file per exit city, downloaded from the app or requested by email
  • Devices behind the router need no software and no setting changed
  • Throughput is limited by the router's processor, not by us
  • The kill switch has to be set on the router, since it is out of the app's reach

If your router cannot run it, a spare computer with two network interfaces will do the same job. Write to securedviewvpn@protonmail.com and we will send the steps for your hardware.
