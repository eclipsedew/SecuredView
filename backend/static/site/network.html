How a node is built

Nothing on a node survives losing power.

Every exit runs its whole system from memory. There is no disk to image, no swap file to recover, and no log directory to subpoena. Pull the power and the machine has nothing to say about anyone who used it.

Storage

Memory only

The operating system is loaded over the network at boot and lives in RAM for the life of the machine. Disks are physically absent from the chassis, not merely unused.

Ownership

Bought, not rented

We own the machines and rent only the rack, the power and the transit. No shared tenancy and no provider with a hypervisor sitting above our traffic.

Name resolution

Resolved on the node

Each node answers its own lookups rather than passing them to a public resolver, so your queries never leave the tunnel to reach a third party.

Adding sites

We add a country when we can hold it properly, not when it looks good on a count.

Plenty of providers advertise a country by renting one virtual machine inside it. We would rather have 61 countries we can describe honestly than 90 we cannot. When a site cannot meet the memory only rule or we cannot own the hardware, it does not go on the map.
